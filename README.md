# 🐍 Python Basics – Exercises and Projects

Este repositório contém exercícios e pequenos projetos desenvolvidos em **Python**, com foco no aprendizado de lógica de programação, operadores lógicos, condicionais e cálculos matemáticos.

## 📂 Projetos incluídos

- `triangle_checker.py` → Verifica a possibilidade de formar um triângulo a partir de 3 lados.  
- `salary_increase.py` → Calcula o aumento de salário baseado em porcentagem.  
- `bmi_calculator.py` → Calcula o Índice de Massa Corporal (IMC).  
- `basic_calculator.py` → Calculadora simples com operações básicas.  
- `logic_operators.py` → Exemplos de uso dos operadores lógicos `and`, `or`, `not`.
